# 수학결 · 중학교 수학 시험 분석 MVP

한국어 로컬 웹 앱입니다. **1단계 MVP만 구현**했으며 PDF/Excel 보고서 출력, 학교별 시험 비교, 장기 출제 경향 분석은 포함하지 않습니다.

## Windows에서 실행

1. [Python 공식 사이트](https://www.python.org/downloads/windows/)에서 **Python 3.11 또는 3.12, 64비트**를 설치합니다. Python Launcher(`py`)를 포함해 설치하세요.
2. 프로젝트 ZIP을 쓰기 가능한 폴더(예: `문서\exam-mvp`)에 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
3. `install.bat`를 더블 클릭합니다. 최초 실행에는 인터넷이 필요하며 무료 오픈 소스 패키지를 설치합니다.
4. 설치가 끝나면 `start.bat`를 실행합니다. 브라우저가 자동으로 열립니다. 자동으로 열리지 않으면 주소창에 `http://127.0.0.1:5000`을 입력하세요.
5. 종료하려면 실행 창에서 `Ctrl+C`를 누르세요. 다시 `start.bat`를 실행해도 저장한 시험지는 유지됩니다.

설치 오류는 실행 창에 표시됩니다. 5000 포트를 다른 프로그램이 사용하면 해당 프로그램을 종료한 뒤 실행하세요. 이 앱은 한 PC의 한 사용자용이며 인터넷에 공개하거나 `0.0.0.0`으로 실행하지 마세요. Windows 배치 파일은 제공했으나 실제 검증은 Linux/Python 3.12에서 수행했습니다.

macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

## 바로 시험해 보기 · 유료 API 불필요

1. 새 시험지 등록에서 `samples/sample-text.pdf`를 선택하고 학교·학년·연도·학기를 입력합니다.
2. 등록하면 3개 문항을 분리합니다. 3번의 소문항은 2페이지에 이어집니다. 샘플은 직접 제작한 **가상 시험지**이며 실제 기출 분석 결과가 아닙니다.
3. 왼쪽에서 원본 페이지를, 오른쪽에서 문항별 원문·배점·단원·유형·근거를 확인합니다.
4. 1번 문항의 형태를 `단답형`, 유형을 `계산`으로 선택하고 평가 요소 5개를 모두 `1점`으로 입력합니다. 결과는 25점, `하`입니다.
5. 필요하면 교사 최종 난이도를 별도로 변경하고 근거를 기록합니다. `문항 저장`을 누르세요.
6. `수정 이력`에서 수정 전후 값을 확인하고, `시험지 통계`에서 문항 수·확인 배점·단원·난이도·유형별 분포를 확인합니다.
7. 목록으로 돌아가거나 서버를 종료·재시작한 후 같은 시험지를 다시 열어 저장을 확인합니다.
8. `sample-image.png`, `sample-scan.pdf`는 AI 미설정 시 자동 문항이 없는 상태로 저장됩니다. 원본을 보면서 `문항 추가`로 입력하거나 아래 AI 설정을 사용하세요.

문항의 번호·원문·소문항·페이지 범위·배점·단원·성취기준·형태·유형·개념·출제 특징·판단 근거·검토 상태를 수정할 수 있습니다. 인식이 잘못 분리된 문항은 원문을 복사해 합친 뒤 불필요한 문항을 삭제하세요. 문항 삭제는 해당 수정 이력도 삭제하며 원본 파일은 보존합니다. 소문항은 현재 문항 원문 안에 저장하며 독립적인 소문항별 난이도·대표 난이도 정책은 미구현입니다.

## 인식·분석 모드의 차이

| 항목 | API 없이 사용 | 외부 AI 설정 후, 사용자 승인 시 |
|---|---|---|
| PDF/JPG/PNG 원본 저장·미리보기 | 가능 | 가능 |
| 텍스트 PDF 문항 분리 | 줄 시작의 `1.` / `1)` 등 명시된 번호 기준 | 페이지 이미지를 이용한 인식 |
| 이미지·스캔 PDF 자동 인식 | 미지원, 수동 입력 | Vision 모델에 요청 |
| 단원 | 키워드 기반 예비 대단원 제안 | 모델 제안, 교사 확인 필요 |
| 유형·난이도·풀이 근거 | 자동으로 추측하지 않음, 교사가 입력 | 모델이 평가 요소·풀이 근거 제안 |
| 통계·저장·수정·재열기 | 가능 | 가능 |

**규칙 기반 예비 인식은 AI 분석이 아닙니다.** 어려운 다단 편집, 번호 없는 문제, 머리말, 페이지가 바뀌는 문제의 경계를 잘못 인식할 수 있습니다. 미확인 배점은 0점으로 확정하지 않으며 난이도는 미평가로 남깁니다. 원본 페이지는 항상 보존하고 AI 결과로 수식·그림을 대체하지 않습니다. 자동 영역 박스, 도형을 독립 객체로 복원하는 기능, 수식 LaTeX 변환은 없습니다. 원문은 텍스트로 보여주며 원본 수학 표기는 이미지로 대조해야 합니다.

## 관리자 API 설정과 비용 내역

왼쪽 **관리자 설정** → 초기 비밀번호 **5162** → OpenAI API 키 입력 → 모델 선택 → **설정 저장** 순서로 사용합니다. 기본 모델은 GPT-4.1 mini이며 GPT-5 mini·GPT-4.1 또는 직접 등록한 OpenAI 이미지 지원 모델로 변경할 수 있습니다. 키 저장 자체는 유료 호출을 하지 않습니다.

시험지를 열고 **외부 AI로 인식·분석**을 누르면 예상 비용을 확인하고 호출을 승인할 수 있습니다. 사용 토큰 기반 호출별 추정 비용·합계는 관리자 설정에서 볼 수 있습니다. 자세한 계산·보안·저장 범위는 [AI_SETTINGS.md](AI_SETTINGS.md)를 참고하세요.

API 키는 암호화된 HttpOnly 쿠키로 브라우저별 보관하고 응답에 원문을 반환하지 않습니다. 별도 Vercel API 키 환경변수는 필요하지 않습니다. 관리자 로그인은 30분간 유효합니다. 외부 AI 사용 시 시험지 이미지와 시험 정보가 OpenAI에 전송됩니다. 개발 중에는 유료 API를 호출하지 않았으며 실제 시험지 분석 정확도는 교사 검증이 필요합니다.

## 난이도 계산

개념 복잡성 25%, 사고력·추론 30%, 풀이 과정 20%, 계산 복잡성 10%, 조건 해석 15%를 사용합니다. 각 요소 0~4점이며 `합계(요소점수 / 4 × 가중치)`로 0~100점을 계산합니다.

- 0 이상 20 미만: 최하
- 20 이상 40 미만: 하
- 40 이상 60 미만: 중
- 60 이상 80 미만: 상
- 80 이상 100 이하: 최상

교사의 최종 난이도는 계산 결과와 별도로 보존합니다. 통계에는 교사 최종 판정이 있으면 우선 적용합니다. 교사 검토 완료는 단원·유형·형태·배점·난이도가 채워져야 선택할 수 있습니다. 통계는 저장된 데이터에서 바로 다시 계산하며 미확인 값은 별도로 표시합니다. 가중치는 현재 `analysis.py`의 `WEIGHTS`에 정의되어 있으며 사용자 설정 화면은 없습니다.

## 저장·백업·개인정보

- SQLite DB: `data/exam.sqlite3`. 시험 정보, 문항, 최초 AI 제안, 교사 수정 전후 전체 기록을 저장합니다.
- 원본·미리보기: `data/<시험 ID>/original.*`, `preview.pdf`.
- `data/.session-key`: 로컬 브라우저 세션 보호 키. 배포 ZIP에는 포함하지 않습니다.
- 서버 종료 후 **data 폴더 전체**를 복사하면 백업할 수 있습니다. 새 설치에 폴더를 복원하면 재열기가 가능합니다. DB만 복사하면 원본이 누락됩니다.
- 시험지 원본과 문항 DB는 암호화하지 않습니다(API 키는 별도 암호화). PC 사용자 계정 권한과 디스크 암호화를 사용하세요. 계정별 접근 제어나 다중 사용자 운영은 미지원입니다.
- 시험지 단위 삭제 화면은 미구현입니다. 모든 자료를 지우려면 서버를 종료하고 data 폴더를 삭제하세요. 개별 문항 삭제 및 원본 다운로드는 지원합니다.
- 업로드는 최대 30MB, 암호 없는 최대 30페이지입니다. 확장자뿐 아니라 실제 파일 형식을 확인합니다.
- 로컬 호스트 제한, CSRF 토큰, HTML 텍스트 이스케이프, SQL 매개변수화를 적용했습니다. 보안 감사나 인터넷 공개 서비스용 배포 검증은 수행하지 않았습니다.

## 기능 테스트

Windows: `test.bat` 실행. 수동 명령:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

테스트는 임시 폴더를 사용하며 실제 저장 데이터를 변경하거나 유료 API를 호출하지 않습니다. 테스트 항목 및 실제 실행 결과는 `TEST_REPORT.md`를 확인하세요. 가상 샘플 생성은 `python make_samples.py`입니다. 기존 샘플 파일을 다시 생성하므로 수정해 둔 샘플은 먼저 복사하세요.

## 기술 구조와 확장 경계

Flask(Python 3.11+)로 API와 HTML을 제공하고 PyMuPDF로 PDF 텍스트 추출·이미지 페이지 렌더링을 수행합니다. SQLite는 별도 서버 설치 없이 Windows에서 저장·백업할 수 있습니다. 화면은 외부 CDN이나 Node.js 빌드 없이 HTML/CSS/JavaScript로 동작합니다. Flask/Jinja 전이 의존성은 pip에서 해결하며 주요 직접 의존성은 버전을 고정했습니다. Windows/로컬 단일 사용자 워크플로에 맞춘 선택입니다.

처리 흐름: 업로드 → 파일 형식/크기/페이지 확인 → 원본 보존 → 텍스트 PDF 번호 분리 → 예비 문항 저장 → 선택적 AI 이미지 분석 → 응답 검증 및 트랜잭션 저장 → 원본 대조/교사 수정 → 변경 이력 기록 → 통계 재계산.

DB 구조: `exams` 1:N `questions` 1:N `revisions`. 문항 분석 JSON은 교사의 현재 결과와 `ai_snapshot` 최초 AI 제안을 구분합니다. API 응답이 모두 유효할 때만 기존 예비 문항을 교체합니다. 단일 프로세스·단일 사용자 서버로 동시에 여러 편집자가 작업하는 용도가 아닙니다.

50~100개 실제 기출문항을 이용한 교사 판정 비교, 일치율·한 단계/두 단계 이상 차이 평가, 독립 소문항 모델, 교육과정 공식 매핑, 인식 영역 조절, 비동기 작업 큐는 아직 구현하지 않았습니다. 실제 기출문항과 교사 정답 기준이 제공되지 않아 품질 검증을 완료했다고 주장하지 않습니다. PDF/Excel 출력·학교별 비교·장기 경향 분석은 요청에 따라 2~4단계로 남겨 두었습니다.

## Vercel 배포

GitHub 저장소를 연결하는 순서와 환경 변수는 [VERCEL.md](VERCEL.md)를 참고하세요. Vercel 구성은 시험지에 대해 브라우저별 **임시 저장 체험용**이며, 관리자 설정에 API 키를 등록하고 승인하면 외부 AI 분석을 사용할 수 있습니다. 로컬 저장과 같은 영구 보관을 제공하지 않습니다.
